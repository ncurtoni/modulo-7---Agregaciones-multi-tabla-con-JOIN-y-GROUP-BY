# modulo-7---Agregaciones-multi-tabla-con-JOIN-y-GROUP-BY
Script SQL que arma una tabla de features por cliente a partir de 4 tablas relacionadas (clientes, pedidos, detalles_pedido, productos): LTV con LEFT JOIN, gasto por categoria con CASE WHEN, segmentacion con HAVING, y ranking por ciudad con funcion de ventana. Ejecutable en DuckDB o SQLite.
